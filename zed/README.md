# Zed

Copy `settings.json`, `AGENTS.md`, and the JSON file in `themes/` to `%APPDATA%/Zed`, preserving the directory layout. `extensions.txt` lists installed extension IDs; install the desired extensions through Zed, including `colored-zed-icons-theme` for the selected icons.

The bundled Catppuccin Blur theme is version 0.4.0 from https://github.com/jenslys/zed-catppuccin-blur. Its MIT license is included in `themes/LICENSE.catppuccin-blur`. The active variant is `Catppuccin Macchiato (Blur) [Light]`. Alternatively, install the `catppuccin-blur` extension instead of copying the theme JSON.
