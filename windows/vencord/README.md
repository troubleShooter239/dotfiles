# Vencord

Close Discord and copy `settings/` to `%APPDATA%/Vencord/settings/` after backing up the existing files. Install Vencord separately first.

The snapshot contains plugin preferences and an empty `quickCss.css`. No custom themes were installed: the local `themes/` directory, `themeLinks`, and `enabledThemes` were empty. Discord account data, caches, and Vencord binaries are excluded.
