# YASB — Windows

The config.yaml file defines bar placement and widgets. The styles.css file defines their appearance. The yasb_colors.css file is a generated Windows-color snapshot.

## Apply

1. Install YASB and the JetBrainsMono Nerd Font referenced in styles.css.
2. Back up %USERPROFILE%/.config/yasb/. If YASB_CONFIG_HOME is set, use that directory instead.
3. Exit YASB and copy config.yaml, styles.css, and yasb_colors.css into the configuration directory.
4. Start YASB and check the bar on your monitors. Adjust screen selection, paths, shortcuts, and weather options as needed.

This configuration includes Komorebi workspace/layout widgets. Install and run Komorebi to use them, or remove those widgets from the bar and configuration. The home menu uses Windows user folders. Styles also reference Windows system fonts.

The yasb_colors.css file may be regenerated by YASB; its colors are a snapshot rather than a portable system theme. The saved configuration has system_colors: false.

This setup uses Windows widgets and integrations; it is not a configuration for Linux/macOS status bars.
